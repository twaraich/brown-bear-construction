# Logo Files

Drop the official Brown Bear Construction logo files in this folder.

Suggested files to add:
- `logo.svg` — vector version (best for the web, scales cleanly)
- `logo.png` — high-resolution PNG with transparent background
- `favicon.ico` or `favicon.png` — small icon for the browser tab

Once uploaded, update the header in each HTML page to use an `<img>` tag pointing to the logo file instead of the text placeholder.
