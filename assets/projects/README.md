# Project Photos

Store project photos here. One folder per project keeps things tidy as the portfolio grows.

Example:
```
assets/projects/
  lakeside-home/
    hero.jpg
    kitchen.jpg
    exterior.jpg
```

Tips:
- Use JPG for photos, PNG for graphics with transparency.
- Aim for images under 500 KB each so pages load fast. Most image editors can export a compressed version.
- Wide, landscape-oriented photos generally look best on the web.
